Preguntas Contenido de ejemplo

Preguntas frecuentes

¿Pueden integrarse con las herramientas que ya usamos?

Sí. Partimos de vuestro entorno actual y nos conectamos a él, sea un CRM, una base de datos o sistemas internos.

¿De quién es el código y el contenido?

Vuestro. La solución, el código y el contenido se entregan al finalizar el proyecto.

¿Cuánto dura un proyecto típico?

Un sitio web o un asistente suele ser cuestión de semanas; una app a medida depende del alcance. Lo definimos en la propuesta.

¿Ofrecen soporte después del lanzamiento?

Sí. Podemos quedarnos como vuestro socio tecnológico, con soporte, monitoreo y mejoras.

¿El asistente puede funcionar en inglés y español?

Sí. Diseñamos asistentes y sitios para que funcionen en ambos idiomas.
